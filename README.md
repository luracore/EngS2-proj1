# EngS2-proj1
Projeto 1 de Engenharia de Software 2
Aplicação WEBGIS que mostra estabelecimentos em uma área no mapa.
O tipo de estabelecimento e o diâmetro da área podem ser escolhidos.
Os estabelecimentos tambem geram uma lista com seus dados.
Ao clicar no item da lista, o mapa centraliza no estabelecimento
